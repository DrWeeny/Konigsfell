# Königsfell : Les Trames du Onzième

> Cette aventure de dark urban fantasy place votre table au cœur d'une intrigue politique dans la cité de Königsfell. Les joueuses et joueurs pourront influencer l'avenir de la région et résoudre de nombreuses situations à multiples issues.

## 🎲 À propos

**Königsfell : Les Trames du Onzième** est un projet de jeu de rôle papier (JDR) sous forme de livret web.

- **Tonalité** : sombre, politique, urbain
- **Style de jeu** : missions, double jeu, renseignement
- **Objectif** : réunir des fragments d'informations dangereuses pour faire basculer le futur de Königsfell
