# Roll20 : inventaire des notes à importer

*La campagne du Sucret est tenue dans Roll20 (journal du MJ). Le MJ en colle les notes au fil des sessions de travail ; ce fichier dit ce qui est déjà dans le dépôt et ce qui reste.*

**Lire les points de couleur.** Chaque point est un joueur qui a accès à la note ; un seul point bleu clair veut dire que tous les PJ la connaissent.
